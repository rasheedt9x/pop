# Pop

A small touch arcade game for Android, written in C with raylib and built entirely on the phone with
[raylib-android](https://github.com/rasheedt9x/raylib-android).

Orbs swell up and fade away: tap them before they're gone. Pops in a row build a combo (and raise the pitch),
tapping empty space breaks it, and every orb that fades out costs one of three lives. It speeds up as you go.

## Build

Clone it next to the kit:

```sh
git clone https://github.com/rasheedt9x/raylib-android
git clone https://github.com/rasheedt9x/pop
cd pop
./build.sh     # pop.apk (also copied to Downloads)
./dev.sh       # hot reload while you edit src/game.c
```

The art, sounds and music in `assets/` and `icon.png` are generated by `tools/gen-assets.c`
(`./tools/gen-assets.sh`). Swap in your own files with the same names if you like.

## Roadmap

- **Online leaderboard.** The networking is already there (`NetPost`/`NetGet` in the kit), so this only needs a
  backend. That part is up to whoever runs the game: a small Cloudflare Worker, Supabase, Firebase or your own
  server. Scores would be submitted on game over and the top list shown on the title screen.
