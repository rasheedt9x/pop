# Pop

Working notes for whoever picks this up next (Claude or the user).

A raylib touch game built with ../raylib-android (read its NOTES.md first). Started 2026-10-11.

## Game (src/game.c)
Orbs grow, hold, then shrink away; a ring shows each one's time left. Tap one to pop it (score += combo, pitch rises
with the combo). Tapping empty space resets the combo; an orb that fades out costs one of 3 lives. Spawn rate and
orb lifetime tighten over time. Multi-touch: each new touch id in a frame counts as a tap. Best score is saved to
best.dat in the app's private files. All state is in `Game` (hot reload keeps it).

## Assets
assets/images (orb is near-white and tinted per orb; glow/spark drawn additively), assets/sounds (*.wav, music.qoa
= a 16 s ambient loop, Am F C G), icon.png. All generated by tools/gen-assets.c (`./tools/gen-assets.sh`, uses
Termux's desktop raylib); any of them can be replaced by hand-made files with the same names.

## Build
./dev.sh (hot reload), ./build.sh [install] (release pop.apk). Same package (local.pop) for both, same key.
